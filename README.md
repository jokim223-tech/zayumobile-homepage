# 자유통신 후불 홈페이지 구축

자료 대조일: 2026-10-21. 진리모바일 선불 홈페이지와 별도 프로젝트.

## 실행

index.html을 열거나 저장소 루트에서 `python3 -m http.server 8000` 실행 후 접속합니다. 외부 패키지나 빌드 과정이 없는 반응형 정적 홈페이지입니다. plans.json은 원본 데이터이며 index.html은 plans-data.js를 사용합니다. 수정 후 `python3 scripts/sync-data.py`를 실행하세요.

## 현재 기능

- 31개 자료 항목: KT 15, LG LTE 13, LG 5G 3. 공식 상품 코드가 없어 유일한 판매 상품 31종으로 확정하지 않음.
- 검색, 통신망/세대/가격 필터, 요금순 정렬, 최대 3개 비교, 제휴 안내, 원본 이미지, FAQ, 전화 연결.
- 사용자가 지정한 가입 URL과 자유통신 카카오 URL을 config.js와 HTML에 연결. 실제 신청 화면의 후불 지원·대리점 귀속은 미검증.
- 개인정보 입력 및 신청서 저장 없음. 외부 가입 페이지 연결형 홈페이지.

## 공개 전 해결할 사항

1. 사용자 제공 가입 URL의 후불 KT/LG 지원 및 자유통신 대리점 귀속 확인. 태블릿번호 2931249은 자동으로 URL에 넣지 않음.
2. 사용자 제공 자유통신 카카오채널 주소 연결 완료. 실제 채널 화면·상담 수신 확인 필요.
3. 현행 판매 여부, 공식 상품명/코드, 부가세, 할인 기간 및 종료 후 요금, 초과요율 확인.
4. KT 소진 후 속도, 제휴 혜택 선택/동시 적용 및 유지/등록/지급/만료 조건 확인.
5. 가입자 유형별 인증, 신규/번호이동, 유심/eSIM/단말, 개통 시간, 비용 및 약정 확인.
6. 운영자 사업자 정보와 약관·개인정보 처리방침 확보.
7. 브라우저 PC/모바일 실측 및 실제 링크/개통 점검 후 index.html의 noindex,nofollow를 수정. 검토본은 검색 노출을 차단하되 이는 접근제어가 아니므로 비공개 저장소/호스팅 사용 권장.

## GitHub 배포

연결 저장소: https://github.com/jokim223-tech/zayumobile-homepage
2026-10-21 읽기·쓰기 권한 확인. 첫 소스 반영 진행. 실제 Pages 배포는 별도 확인 필요.

1. 자유통신 전용 GitHub 저장소를 만들고 이 폴더 내용(숨김 .github 포함)을 업로드합니다. 선불 저장소를 덮어쓰지 않습니다.
2. Settings → Pages → Source: GitHub Actions 선택.
3. Actions에서 Deploy Zayumobile to Pages 워크플로를 수동 실행하면 필요한 파일만 site 디렉터리로 묶어 Pages에 배포합니다. 저장소 업로드만으로 자동 공개되지는 않습니다. docs/original-draft.html과 README는 공개 파일에서 제외.
4. 공식 가입 조건 확인 전에는 공개 Pages 배포를 실행하지 말고 비공개 검토 환경을 사용합니다. 일반 GitHub Pages는 URL 보유자가 접근할 수 있습니다.
5. 실제 URL에서 CSS/JS/이미지, 모바일 폭 360/390/768px, PC 1280px, 키보드, 전화·카카오·가입 링크, 외부 가입 귀속을 확인합니다.
6. 정상 릴리스 커밋을 기록합니다. 문제 발생 시 직전 정상 커밋으로 revert하고 다시 배포합니다.

## 수정 구조

- index.html / style.css / app.js: 화면과 동작
- plans.json / plans-data.js: 요금표와 브라우저용 사본
- config.js: 확인된 실제 가입/상담 URL만 입력
- assets/: 원본 근거 이미지 3장
- docs/project-plan.html: 자료검토·실행계획·체크리스트
- .github/workflows/pages.yml: 수동 실행 배포

검토본 가격은 제공 이미지와 일치한다는 뜻이며 현재 공식 판매 가격 확인을 뜻하지 않습니다. 각 요금제의 혜택 이름은 자료 표기에 따른 설명용 명칭입니다.
